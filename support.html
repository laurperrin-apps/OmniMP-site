Support

Vous avez repéré une erreur, un lien inactif ou un problème d’affichage ? Vous pouvez le signaler sur le dépôt GitHub d’OmniMP.

Signaler un problème Voir les signalements
Les signalements GitHub peuvent être publics. Ne publiez aucune donnée médicale, information personnelle, document de santé, nom d’employeur ou détail permettant d’identifier une personne.

Pour faciliter le traitement

  • indiquez le modèle de votre iPhone ou iPad ;
  • précisez la version d’iOS et celle de l’application ;
  • décrivez les étapes qui provoquent le problème ;
  • pour une erreur de contenu, indiquez la rubrique et la source concernées, sans joindre de données personnelles.

Une question sur une situation de santé ?

Le support d’OmniMP ne peut pas déterminer si une maladie individuelle sera reconnue. Pour un dossier personnel, adressez-vous à l’organisme compétent selon votre régime ou à un professionnel qui connaît votre situation.
