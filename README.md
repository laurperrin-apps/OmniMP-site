# OmniMP-site

Site officiel en français pour l’application OmniMP.

## GitHub Pages

Dans le dépôt `laurperrin-apps/OmniMP-site` :

1. Ouvrir **Settings > Pages**.
2. Choisir **Deploy from a branch**.
3. Sélectionner `main` et `/ (root)`.
4. Enregistrer.

L’adresse attendue est `https://laurperrin-apps.github.io/OmniMP-site/`.

## Pages

- `index.html` : présentation de l’application et de ses rubriques.
- `support.html` : aide et signalement d’un problème via GitHub Issues.
- `privacy.html` : politique correspondant au prototype actuel.
- `styles.css` : style responsive en vert et jaune.
- `.nojekyll` : désactive le traitement Jekyll.

La page de confidentialité décrit seulement le prototype actuel. Elle devra être revue si l’application ajoute de nouveaux traitements ou services.
